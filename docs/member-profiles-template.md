# メンバー特徴ヒアリングシート

**目的**: Higgsfield でキャラクター画像を生成する際のプロンプト素材。
**対象**: 9名（5v5 = 10枠だが、1名分は重複 or ボット）
**使い方**: 各スロットに「ビジュアル特徴」「象徴的なもの」「キャラ性」を埋める。後で asset agent がプロンプト化する。

---

## 記入のコツ

### 似顔の精度より「識別できる」を優先
実写そっくりは不要。「あ、あの人だ」と分かる **最も特徴的な1〜2要素** を抽出する。

例:
- ❌「目が大きめで鼻筋が通っていて…」（細部すぎる）
- ⭕「丸メガネ + 短い黒髪 + パーカー」（識別キーが3つ）

### 押さえるべき項目
- **髪型・髪色**: ベリーショート / ミディアム / 坊主 / パーマ etc.
- **顔まわり**: メガネ（形状）・ヒゲ・ホクロなど象徴的なもの
- **体型**: 細身 / 標準 / がっしり
- **服装の傾向**: スーツ系 / カジュアル / ロゴT / アウトドア etc.
- **象徴的な小物**: 帽子・アクセ・タトゥー etc.
- **キャラ性**: 真面目 / お調子者 / クール / 兄貴肌 etc.（ポーズや表情に反映）

## Higgsfield プロンプト雛形（asset agent が使用）

```
A 3D game character of a [体型] Japanese [年代] man,
[髪型・髪色], [顔まわり特徴], wearing [服装],
[象徴的な小物],
[キャラ性] expression,
full body turnaround sheet (front / side / back views),
neutral T-pose, white background,
stylized FPS game character, slight cell-shaded look,
clean topology suitable for 3D conversion.
```

---

## 注意事項

- **本人の許諾を取る**: メンバー本人にキャラ化することを伝えて承諾を得る
- **ハラスメント回避**: コンプレックスを誇張するような特徴の入れ方は避ける
- **チーム識別との両立**: モデル自体に赤/青を入れない（バンダナで識別）
- **生成画像の保管**: 採用画像は `assets/characters/_source/<id>/` に元画像を残す（再生成用）
